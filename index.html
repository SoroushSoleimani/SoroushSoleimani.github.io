about

I'm Soroush Soleimani, a software engineer who gravitates toward the parts of a system most people avoid: process pools, mutexes, race conditions, and the plumbing that keeps a distributed pipeline from falling over under load.

My recent work spans a production-style Retrieval-Augmented Generation system built on Django, Celery, Redis, and ChromaDB; a POSIX-compliant C program that executes shell commands in parallel with a custom process-pool architecture; and a real-time facial emotion recognition pipeline trained on the FERPlus dataset. I also contribute to open-source projects including scikit-learn.

Outside of AI/ML infrastructure, I've built multithreaded systems in Java, written a web crawler for large-scale data collection, and designed a GitHub-data-driven developer matchmaking tool. I care about code that stays correct when things run at the same time — that's the thread through most of what's below.
